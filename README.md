# IRIV_COMPRESSOR

Industrial compressor monitoring system using RS485 Modbus RTU communication with real-time monitoring and dashboard visualization.

## Features
- 3x Temperature & Humidity Sensors
- 3-Phase Power Meter Monitoring
- Flow Meter Monitoring
- Pressure & Temperature Sensor
- RS485 / Modbus RTU Communication
- Real-time Monitoring using Node-RED
- Dashboard Visualization
- Industrial Data Acquisition System

## System Overview
This project integrates multiple industrial sensors into a centralized monitoring system for compressor performance monitoring, environmental monitoring, and energy analysis.

All sensors communicate through RS485 Modbus RTU for reliable industrial communication and long-distance data transmission.
